# M11b: `graft draft --skeleton` on freeq-lite v1, a real run (n=1 anecdote)

Model for the skeleton: `opus` (graft's default). Model for the bodies: `haiku`,
`graft run --render --skeleton <the proposal> --accept`. Costs are the sum of
`total_cost_usd` over every call (`claudecost.sh`), spec `spec/freeq-lite.md`,
conventions `conventions.md`. Oracle: held-out, 47 checks.

The final run (draft 4) is the one the tree below was rendered from. It is
**the fourth try, after three prompt/validation fixes that each came from a
failure of the run before**, so it is not a first-shot result; all four are
listed.

| run | draft | draft cost | accepted, rendered with Haiku | render cost |
|---|---|---|---|---|
| 1 | no valid proposal in 3 calls: the model named a section's file `unknown.go`, but a record owns the file `accept` derives (`everything_else.go`) | $1.286 | n/a | n/a |
| 2 | valid, 1 call, no UNOWNED | $0.504 | 0/7: `Running` failed "no dead functions" 3x: the model made every handler a stub, so nothing live called them yet | $0.046 (3 calls) |
| 3 | valid, 1 call, no UNOWNED | $0.417 | 0/7: `Running` failed the visible smoke 3x: `Everything else` had only consts, so no region, so its check ran before Registration existed | $0.042 (3 calls) |
| 4 | valid, 1 call, no UNOWNED | $0.401 | **7/7 applied, oracle 47/47**, 7 calls, 1 attempt each | $0.077 |

Fixes: run 1 -> the prompt names each section's one file, and the structure
check enforces it. Run 2 -> prompt: a stub is a cross-file contract, not one per
handler. Run 3 -> prompt and check: every file needs a stub (its own gated
region). Total spend for all four: $2.77 (draft $2.61 with its three retries
in run 1; bodies $0.17).

Wall: draft 1m37s (run 4); render 1m39s. The skeleton is drafted once; it rarely changes.
